PUBLISH ON GITHUB PAGES
1. Extract the zip archive to a normal folder.
2. Open your GitHub repository (felixnovoac97/portfolio. or portfolio if renamed).
3. Use Add file > Upload files and drag in the extracted CONTENTS, not the ZIP file itself.
4. Replace index.html and upload css/, js/, assets/ (maintain the folders).
5. Commit changes and check Actions > pages build and deployment.
6. Refresh the published site using Ctrl+Shift+R.
